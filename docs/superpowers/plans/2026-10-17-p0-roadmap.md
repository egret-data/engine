# P0 Core Read Engine — Roadmap

> Index of the P0 milestones. Each milestone gets its own detailed implementation plan
> (`docs/superpowers/plans/<date>-p0-mN-<name>.md`), written when the previous milestone is merged so that it builds
> on real code instead of guessed APIs.

**Spec:** [`docs/superpowers/specs/2026-10-17-egret-engine-p0-core-design.md`](../specs/2026-10-17-egret-engine-p0-core-design.md)

## Workflow

Every milestone follows the repository's open-source workflow (see `CONTRIBUTING.md`):

1. Open a GitHub issue `P0/Mn: <name>` (labels `enhancement`, `p0`) linking this roadmap and the milestone plan.
2. Work on branch `feat/p0-mN-<name>`; one commit per plan task (Conventional Commits).
3. Open a PR with `Closes #<issue>`; CI must pass; squash-merge.
